# EIS Analysis Project

This repository contains tools for processing, visualizing, and fitting Electrochemical Impedance Spectroscopy (EIS) data generated by Biologic software.

## Cross-Platform Setup (Windows, macOS, Linux)

To ensure this analysis works seamlessly across different operating systems, follow these steps to set up a virtual environment and install the required dependencies.

### 1. Create a Virtual Environment
Open your terminal or command prompt and run:
```bash
# On Windows
python -m venv .venv

# On macOS and Linux
python3 -m venv .venv
```

### 2. Activate the Virtual Environment
```bash
# On Windows
.\.venv\Scripts\activate

# On macOS and Linux
source .venv/bin/activate
```

### 3. Install Requirements
Once activated, install all necessary libraries using the provided requirements file:
```bash
pip install -r requirements.txt
```

### 4. Running the Notebook
Start Jupyter by running:
```bash
jupyter notebook
```
Then open `EIS_analysis.ipynb`.

## Data Management
- **Raw Data:** Biologic binary `.mpr` files should be exported to `.mpt` (tab-separated text) from the EC-Lab software for robust parsing across all platforms.
- Place all `.mpt` data files into the `data/` directory.

## Best Practices Used in this Repository
- **Cross-Platform Paths:** All Python scripts and notebooks use the standard library `pathlib` for file paths to avoid issues with backslashes (`\`) on Windows vs forward slashes (`/`) on UNIX systems.
- **Dependencies:** Explicitly managed through `requirements.txt`.
